# AETA-Dataset

一部分来自于 AETA 系统中的数据、波形图与 AETA 系统白皮书。

 A part of dataset, white paper and waveforms from AETA System.

---

实验使用的 AETA 系统的原始数据集、波形图与 AETA 系统白皮书在此开源库上提供。

但请注意，这是由于此项目的原始服务器（www.aeta.cn）遭遇攻击而创建的；

数据版权属于哈威（深圳）科技与北京大学。 

由于保密性，我们不在此开源库中提供处理与清洗后的数据与 NS-AEM 的原始代码，若您有需要，请联系通讯作者。

---

The raw datasets of the AETA system used in the experiments, waveforms along with the AETA system white paper, is publicly available on this GitHub open-source repository.

However, please note that this repository was established due to an attack on the original server hosting the project data. 

The data copyright remains with Hawei (Shenzhen) Laboratory and Peking University.

For confidentiality reasons, processed and cleaned datasets and the source code of NS-AEM are not included in this repository. Researchers requiring access to these materials should contact the corresponding author via email.
